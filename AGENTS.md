# Project Rules and Agent Instructions

## Bug Fixing & Debugging Guidelines
- **Deep Understanding First**: Before fixing any bug, read and analyze all relevant code files. Do not limit the context to just the line throwing the error.
- **Root Cause Analysis**: Identify and fix the actual root cause of the problem. Do not just patch the symptoms.
- **Explain Before Fixing**: Always provide a clear explanation of the bug's root cause and list the code sections that are affected *before* executing the code changes.
- **Prioritize Accuracy**: Focus on precision and correctness rather than speed. It is better to take more time to ensure a robust fix than to introduce regressions or new bugs.
- **No Guessing**: If information is missing (e.g., data structures, API responses, exact error messages), ask the user for clarification before proceeding with any code edits.
